

  Personal Project: Fard (Islamic Productivity App)
  A comprehensive spiritual tool designed for tracking obligations and spiritual growth.

  Technical Engineering & Architecture
   * Modular Clean Architecture: Structured the project using Domain-Driven Design (DDD) to separate business rules from UI and data layers, ensuring a highly
     maintainable and 100% testable codebase.
   * State Management & Logic: Implemented advanced event-based state management with concurrency controls to handle complex user flows like bulk data entry and
     real-time audio progress.
   * Offline-First Data Engine: Engineered a high-performance NoSQL persistence layer for near-instantaneous queries and full offline functionality, including a robust
     data portability system (JSON Import/Export).
   * Global Time Automation: Developed a custom engine for automatic synchronization of prayer times and notifications, handling complex edge cases like Daylight Saving
     Time (DST) and global timezone transitions.

  Feature Implementation & Systems
   * Background Audio System: Integrated a system-level media service supporting background playback, lock-screen controls, and offline caching for large audio
     datasets.
   * Native System Integration: Developed native OS components for home-screen widgets and scheduled background tasks (WorkManager) to ensure reliability across device
     restarts.
   * Immersive Quran Reader: Built a multi-engine reader supporting both vector-based text rendering and image-based "scanned mushaf" modes with interactive progress
     tracking.
   * Performance Optimization: Tuned UI performance for 60fps animations and implemented precise hardware-haptic feedback to enhance tactile user interactions.

  Quality & Reliability
   * Comprehensive Testing Suite: Developed a rigorous testing pyramid including unit testing for core algorithms, state-logic verification, and end-to-end integration
     testing for critical user paths.
   * RTL & Accessibility: Fully implemented Right-to-Left (RTL) layout support and specialized Islamic typography for a premium, accessible user experience.
